En la seccion "mis juegos" se encuentra el Blocka, al cual se podra acceder para jugar, lo que dirigira al usuario a la pantalla de ejecucion.
- En el juego se podra ver:
  . El nivel en el que estas
  . Un contador de tiempo de ejecucion del nivel
  . El tiempo maximo que se actualiza por nivel (-5s), arranca en 27s (nivel 1).
  . El boton de comenzar nivel.
Se evalua si el tiempo que llevás jugando es mayor o igual al tiempoMaximo, si lo alcanza, se detiene el reloj (derrota) y muestra el modal para reintentar o para volver al menu,
si se completa el nivel se mostrara el modal con el numero del nivel completado, el tiempo que se tardo en realizarlo y los botones para avanzar al siguiente nivel o regresar al menu.
